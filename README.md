# 🏫| Sistema de notas:
Consiste em uma aplicação de console feita em C#, onde é possível inserir algumas notas e receber a sua média, qual a maior ou menor nota, e quantas foram maiores do que 7.

## Orientações do desafio:
**Desafio: Sistema simples de notas**

1. Peça para o usuário informar quantas notas quer cadastrar.
2. Armazene em um array.
3. Mostre:
    -A média geral
    - A maior e menor nota
    - Quantas notas foram acima de 7
